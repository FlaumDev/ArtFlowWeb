# ArtFlowWeb

Публичный сайт ArtFlow для просмотра творческих конкурсов, повышения доверия к организатору и перехода в Telegram-бот для подачи заявки.

## Статус проекта

Сейчас проект находится на этапе **архитектурного проектирования**. Код сайта ещё не создавался.

## Цель MVP

Пользователь должен иметь возможность:

- посмотреть все опубликованные и актуальные конкурсы;
- быстро сравнить их по городу, дате и направлению;
- открыть подробную страницу конкурса;
- увидеть условия, стоимость, сроки, положение и подтверждения надёжности организатора;
- получить ответы на частые вопросы;
- перейти в ArtFlowBot сразу к выбранному конкурсу;
- пользоваться сайтом с телефона, планшета и компьютера.

## Связь с ArtFlowBot

ArtFlowWeb и ArtFlowBot находятся в отдельных GitHub-репозиториях и используют одну PostgreSQL-базу.

- ArtFlowBot управляет конкурсами, FAQ и заявками.
- ArtFlowWeb читает только публичные данные.
- Проекты не импортируют Python-код друг друга.
- Переход к заявке выполняется через Telegram deep link.

Планируемый формат ссылки:

```text
https://t.me/BOT_USERNAME?start=competition_7
```

> В ArtFlowBot v1.1 обработка параметра deep link пока не реализована. Текущий обработчик `/start` открывает обычное главное меню.

## Ближайшие решения

Перед созданием FastAPI-каркаса необходимо:

1. Утвердить минимальные новые поля таблицы `competitions`.
2. Решить, будет ли адрес конкурса использовать `id` или `slug`.
3. Выбрать хранилище для афиш и положений.
4. Подготовить реальные фотографии, отзывы, статистику и контакты.
5. Добавить в бот обработку `?start=competition_ID` отдельным изменением с ручным тестированием.

## Безопасность

- `.env` не хранится в Git;
- публичный сайт получает отдельного пользователя PostgreSQL с правами только на чтение;
- сайт не получает доступ к заявкам, участникам и администраторам;
- значения из БД выводятся с HTML-экранированием;
- подробные ошибки остаются в логах, а не показываются посетителю.
