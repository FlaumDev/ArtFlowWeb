# Изображения ArtFlow

Эта папка предназначена для будущих оптимизированных изображений владельца проекта. Не публикуйте фотографии детей и участников без разрешения.

Ожидаемые имена файлов:

- `hero-main.webp`, `hero-secondary.webp` — около 1600 x 1000 px, WebP, до 350 KB;
- `organizer-1.webp`, `organizer-2.webp` — 800 x 1000 px, вертикальный портрет, WebP, до 200 KB;
- `gallery-01.webp` ... `gallery-06.webp` — ширина 1200-1600 px, WebP, до 300 KB на файл.

После добавления файлов укажите их пути, подписи и alt-тексты в `content/site_content.json`. Отсутствующие локальные изображения автоматически исключаются из выдачи и не создают сломанные элементы на странице.
