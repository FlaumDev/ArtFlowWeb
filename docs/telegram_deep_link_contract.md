# Telegram Deep Link Contract

Документ фиксирует контракт перехода из ArtFlowWeb в ArtFlowBot.

## Формат

Для конкурса с положительным целым ID сайт формирует payload:

```text
competition_{id}
```

Пример для конкурса с ID `7`:

```text
competition_7
```

Полная ссылка:

```text
https://t.me/{BOT_USERNAME}?start=competition_7
```

`BOT_USERNAME` берётся только из настроек ArtFlowWeb. Ведущий символ `@` удаляется. Если username отсутствует или ID не является положительным целым числом, ссылка не формируется.

## Ответственность ArtFlowBot

ArtFlowBot должен обработать команду:

```text
/start competition_7
```

Бот должен:

1. Проверить точный префикс `competition_`.
2. Извлечь числовой ID.
3. Не доверять ID без проверки.
4. Проверить существование и доступность конкурса.
5. При корректном ID открыть сценарий выбранного конкурса.
6. При ошибочном, удалённом или недоступном ID показать обычное стартовое меню.

ArtFlowWeb формирует ссылку, а ArtFlowBot обрабатывает параметр /start competition_{id}, проверяет конкурс и открывает выбранную карточку.
