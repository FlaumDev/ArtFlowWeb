# Бюджеты производительности ArtFlowWeb

Цели применяются к публичным страницам production-сборки. Это бюджеты, а не
заявление о достигнутых метриках Lighthouse.

| Метрика | Цель |
|---|---:|
| HTML стартовой страницы без изображений | не более 100 KiB |
| JavaScript без сжатия | не более 25 KiB |
| Все CSS-файлы без сжатия | не более 75 KiB |
| Hero image для выбранного viewport | не более 150 KiB |
| LCP, p75 mobile | не более 2,5 s |
| CLS, p75 | не более 0,1 |

## Текущий статический baseline

Размеры измерены локально 22 июля 2026 года без gzip/brotli:

- `main.js` — 10 577 bytes;
- CSS суммарно — 57 244 bytes;
- `hero-main-960.webp` — 51 584 bytes;
- `hero-main.webp` — 101 120 bytes.

Hero использует `srcset` и `sizes`, имеет явные `width`/`height`,
`fetchpriority="high"` и `loading="eager"`. Остальные контентные изображения
загружаются лениво. Скрипт подключён с `defer`, а CSS и JavaScript получают
версию в query string для cache busting.

Исходный логотип `artflow-logo.png` (`1280×1280`, 328 848 bytes) сохранён без
изменений. В интерфейсе и favicon используется версия `artflow-logo-512.png`
(`512×512`, 61 474 bytes, без metadata): она на 81% легче и остаётся достаточно
детальной для самого крупного фактического размера отображения.

LCP и CLS необходимо измерить после deployment на реальном мобильном соединении.
Без фактического Lighthouse или RUM-прогона эти цели не считаются достигнутыми.
