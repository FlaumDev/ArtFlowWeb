# User Flows

## 1. Основная конверсия

```text
Реклама / Instagram / WhatsApp / поиск
→ Главная
→ Актуальные конкурсы
→ Страница конкурса
→ Проверка условий и доверия
→ «Подать заявку в Telegram»
→ ArtFlowBot открывает выбранный конкурс
→ Пользователь начинает регистрацию
→ Проверяет данные
→ Отправляет заявку
```

## 2. Пользователь сразу открыл конкретный конкурс

```text
Прямая ссылка на страницу конкурса
→ Информация и доказательства доверия
→ CTA
→ Telegram deep link
→ Тот же конкурс в боте
```

Пользователь не должен повторно искать конкурс после перехода в Telegram.

## 3. Пользователь сомневается

```text
Страница конкурса
→ FAQ
→ Отзыв / положение / информация об организаторе
→ Получил ответ
→ Вернулся к CTA
→ Telegram
```

FAQ, контакты и положение должны быть доступны прямо со страницы конкурса.

## 4. Пользователь не нашёл подходящий конкурс

```text
Все конкурсы
→ Фильтры дали пустой результат
→ Сбросить фильтры
или
→ Перейти в социальные сети / контакты
```

Нельзя показывать пустой белый экран.

## 5. Конкурсов пока нет

```text
/competitions
→ Сообщение «Новых конкурсов пока нет»
→ Ссылка на социальные сети
→ Контакты организатора
```

## 6. Регистрация закрыта

```text
Страница конкурса
→ Статус «Регистрация завершена»
→ CTA подачи заявки скрыт или отключён
→ Показать контакты и другие актуальные конкурсы
```

Нельзя вести пользователя в регистрацию, если подача заявки недоступна.

## 7. Неверный deep link

```text
/start competition_999999
→ Бот проверяет ID
→ Конкурс не найден
→ Понятное сообщение
→ Кнопка «Посмотреть доступные конкурсы»
```

## 8. Правила CTA

Главный CTA:

```text
Подать заявку в Telegram
```

Он размещается:

- в первом информационном блоке конкурса;
- после основных условий;
- в конце страницы;
- закреплённым снизу на телефоне после прокрутки первого экрана.

Второстепенные действия:

- открыть положение;
- задать вопрос;
- посмотреть другие конкурсы.

Они не должны визуально спорить с главным CTA.
